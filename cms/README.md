# CMS

Getrennte Verwaltungsoberfläche mit eigener Backend-Anbindung.

## Module

- Dashboard
- Künstler und Kollektionen
- Produkte, Varianten und Formate
- Rahmen und Custom Frames
- digitale Downloads
- Bestellungen
- Newsletter
- Seiteninhalte
- Medien
- Instagram
- Einstellungen

Das CMS enthält keine Datenbank- oder Stripe-Schlüssel. Es kommuniziert nur mit
der geschützten Admin-API des Backends.
